Riemann Sums

Calculus

Watch how increasing the number of rectangles approaches the true area under the curve. This demonstrates the fundamental concept behind definite integrals.

def riemann_sum(f, a, b, n): dx = (b - a) / n return sum(f(a + i*dx) * dx for i in range(n))

Calculus

Fourier Series

Analysis

Build a square wave from sine components. Watch how adding more harmonics progressively improves the approximation.

# Fourier series for square wave def fourier_square(t, n_terms): return sum(sin((2*k+1)*t)/(2*k+1) for k in range(n_terms))

Calculus

Approximate functions with polynomials. Watch how adding more terms improves accuracy near the expansion point.
