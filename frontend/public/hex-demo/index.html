# Shear transformation matrix = [[1, 1], [0, 1]] self.play( plane.animate.apply_matrix(matrix), i_hat.animate.put_start_and_end_on( ORIGIN, [1, 0, 0]), j_hat.animate.put_start_and_end_on( ORIGIN, [1, 1, 0]) )

How do I make the tangent line animation smoother?
M
The jerkiness comes from linear interpolation. Use rate_func to add easing:
# Smooth easing self.play( t.animate.set_value(2), run_time=4, rate_func=smooth )
Pro tip: smooth gives viewers time to process what they're seeing at the start and end of animations.
